# vibec-studios/.github

Org-wide files for [Vibe Craft Studios](https://github.com/vibec-studios):

- `profile/README.md`: the profile shown on the organization page (banner and icons in `profile/assets/`)
- `.github/ISSUE_TEMPLATE/`: default bug report and idea forms for every repository that has no templates of its own

The banner is a render of the website hero (`https://vibec-studios.github.io/`), 2560 × 800.

## Licensing and policies (all repositories)

- [LICENSING.md](LICENSING.md): code under Apache-2.0, plus the exceptions per repository
- [TRADEMARKS.md](TRADEMARKS.md): forks need their own name and logo
- [ASSETS-POLICY.md](ASSETS-POLICY.md): artwork, models and sounds are all rights reserved
- [SERVICES.md](SERVICES.md): the Vibe online services are for official builds only
- [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md): GitHub shows these in every repository that has
  no file of its own
