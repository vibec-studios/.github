# vibec-studios/.github

Org-wide files for [Vibe Craft Studios](https://github.com/vibec-studios):

- `profile/README.md`: the profile shown on the organization page (banner and icons in `profile/assets/`)
- `.github/ISSUE_TEMPLATE/`: default bug report and idea forms for every repository that has no templates of its own

The banner is a render of the website hero (`https://vibec-studios.github.io/`), 2560 × 800.
